# تم بامرو (Bamero Theme)

تم سفارشی فروشگاه **بامرو** برای WordPress + WooCommerce، کاملاً RTL و فارسی (fa-IR).

## فایل‌های اصلی

| فایل | نقش |
|------|-----|
| `style.css` | شناسنامهٔ تم + استایل‌های پایه |
| `functions.php` | راه‌اندازی تم، enqueue دارایی‌ها، فیلدهای محصول، Schema، امنیت، تنظیمات تم |
| `header.php` | سربالا، نوار بالا، منوی چسبان، جستجو، سبد خرید |
| `footer.php` | پاورقی، اطلاعات تماس، لینک‌های سریع |
| `front-page.php` | صفحهٔ اصلی (hero، دسته‌ها، محصولات) |
| `index.php` | فهرست/آرشیو/جستجو (fallback سلسله‌مراتب قالب) |
| `page.php` | قالب صفحات ثابت — خروجی `the_content()` برای صفحات شورت‌کدی (سبد خرید، پرداخت، حساب کاربری، ورود موبایل) |
| `404.php` / `about.php` / `contact.php` | قالب‌های صفحات ویژه |
| `theme.json` | تنظیمات بلوک‌ادیتور و پالت رنگ |
| `css/` | متغیرها، آیکون‌ها، استایل‌ها، WooCommerce، RTL، storefront |
| `js/main.js` | تعاملات سمت کاربر |
| `woocommerce/` | بازنویسی قالب‌های WooCommerce |

## تنظیمات قابل‌پیکربندی (سفارشی‌سازی)

از مسیر **نمایش > سفارشی‌سازی > اطلاعات تماس بامرو** می‌توانید این مقادیر را بدون ویرایش کد تغییر دهید:

- شمارهٔ تماس (`bamero_phone_number`)
- نشانی (`bamero_address`)
- آدرس اینستاگرام (`bamero_instagram_url`)
- آدرس تلگرام (`bamero_telegram_url`)
- آدرس واتساپ (`bamero_whatsapp_url`)

این مقادیر در سربالا، پاورقی، صفحهٔ تماس و داده‌های ساختاریافته (Schema) استفاده می‌شوند.

## وابستگی‌ها

- WordPress 6.x
- WooCommerce 9.x+ (قالب‌های بازنویسی‌شده از ۹.۰؛ سری ۱۰/۱۱ نیز کار می‌کنند — پس از هر ارتقای major، وضعیت قالب‌ها را در WooCommerce > Status بازبینی کنید)
- فونت Vazirmatn (به‌صورت محلی در `assets/fonts/` قرار دارد)

## نکات امنیتی

- تمام خروجی‌ها با `esc_html` / `esc_attr` / `esc_url` پاک‌سازی می‌شوند.
- اسکریپت‌ها با **CSP nonce** بارگذاری می‌شوند.
- JSON-LD داده‌های ساختاریافته با nonce همراه است.
