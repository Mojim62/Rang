# Bamero Custom Plugin

## توضیحات

این افزونهٔ سبک فقط **صفحات محتوای فروشگاه بامرو** را هنگام فعال‌سازی می‌سازد:

- **مشاوره رنگ** — صفحه‌ای با شورت‌کد `[bamero_color_consultation]` (فرم و پردازش آن توسط تم و هستهٔ production فراهم می‌شود).
- **درباره ما** — با قالب صفحهٔ `about.php` تم.
- **تماس با ما** — با قالب صفحهٔ `contact.php` تم.

این افزونه **هیچ منطق کسب‌وکاری ندارد**؛ نمایش و پردازش فرم‌ها متعلق به تم و افزونه‌های هسته است و در صورت غیرفعال بودن این افزونه، امکانات فروشگاه از کار نمی‌افتد (فقط صفحات از پیش ساخته‌شده باقی می‌مانند).

## نصب

1. پوشهٔ `bamero-custom-plugin` را در `wp-content/plugins/` قرار دهید (در این بسته از قبل موجود است).
2. از پیشخوان، **افزونه‌ها** را باز کنید و **Bamero Custom Plugin** را فعال کنید.

## نکات

- صفحات فقط یک‌بار و در صورت نبود ساخته می‌شوند (`get_page_by_path`).
- در غیرفعال‌سازی، هیچ داده‌ای حذف نمی‌شود؛ فقط rewrite ruleها تازه می‌شوند.

## مستندسازی

برای اطلاعات بیشتر، به فایل `bamero-custom-plugin.php` مراجعه کنید.
